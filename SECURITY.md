# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in ConfigDrift, please report it privately.

- Do not open public issues for security vulnerabilities.
- Use GitHub Security Advisories:
  https://github.com/neel-03/configdrift/security/advisories

Please include:
- Description of the issue
- Steps to reproduce
- Potential impact
- Suggested fix (optional)

Security reports will be reviewed and addressed as quickly as possible.

## Supported Versions

Only the latest versions on the `main` and `development` branches are actively supported.

## Security Practices

This project uses:
- Dependabot
- Static analysis (`gosec`)
- CI validation workflows

Thank you for helping improve the security of ConfigDrift.
